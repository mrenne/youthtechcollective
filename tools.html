Tools & technologies

What teens build with

In our workshops, teens learn hands-on with the same kinds of tools used in classrooms, labs and tech jobs. Here are some of the tools and technologies they'll work with and learn about.

Physical computing

micro:bit

The micro:bit is a pocket-sized computer designed for learning. It has a grid of LED lights, buttons, a speaker, a microphone and built-in sensors that detect motion, direction, light and temperature. It can also talk to other devices by radio and Bluetooth.

Teens program it with drag-and-drop blocks, JavaScript or Python to build things like step counters, games and wearable AI that recognizes their movements.

  • Coding
  • Electronics
  • Sensors
  • AI / machine learning
Learn more at microbit.org →

Artificial intelligence

Google Teachable Machine

Teachable Machine is a free, web-based tool from Google that lets anyone train their own machine learning model without writing code. Teens teach a computer to recognize images, sounds or body poses by showing it examples with a webcam or microphone, then test how well it learned.

It runs right in the web browser with no account needed, and by default the examples stay on the device. Finished models can be used in websites, apps and other projects.
